TECHNICAL SPECIFICATIONS
================================================================================

Technology Stack:
  • Language: Rust (type-safe, memory-safe, zero-cost abstractions)
  • Compile Target: WebAssembly (wasm32-unknown-unknown)
  • UI Framework: Dioxus 0.6 (JSX-like component model)
  • Build Tool: dioxus-cli (dx command)
  • Styling: Vanilla CSS + Custom CSS
  • Data Format: JSON (embedded in WASM binary)
  • Hosting: Cloudflare Pages (static, global CDN)
  • Testing: cargo test (Rust unit tests)
  • Dependency Management: Cargo + Cargo.lock (pinned versions)

Build Process:
  1. dx serve --open          (development with hot reload)
  2. cargo clippy             (lint for warnings)
  3. cargo test               (run unit tests)
  4. dx build --release       (production build with optimization)
  5. dist/ created            (WASM + assets ready for deployment)
  6. git push origin main     (trigger Cloudflare Pages build)
  7. Cloudflare builds        (runs: dx build --release)
  8. Auto-deploy to CDN       (global distribution)

Performance Targets:
  ├─ Bundle Size: < 500KB uncompressed
  ├─ Gzipped Size: < 150KB on wire
  ├─ First Contentful Paint: < 1s (4G)
  ├─ Lighthouse Score: 90+ (all metrics)
  ├─ Response Time (p50): < 100ms
  ├─ Cache Hit Rate: > 95%
  ├─ WASM Load Time: < 200ms
  └─ Time to Interactive: < 2s

Security Compliance:
  ├─ OWASP Top 10:2025 (all 10 categories addressed)
  ├─ CWE Coverage (no injection, XSS, CSRF vulnerabilities)
  ├─ Input Validation (character whitelist, length limits)
  ├─ Rate Limiting (10 requests/second per browser)
  ├─ No Hardcoded Secrets (environment variables only)
  ├─ Dependency Audits (cargo audit, zero known vulns)
  ├─ Rust Memory Safety (no buffer overflows, no use-after-free)
  └─ CSP Policy (default-src 'self', strict evaluation)

Cost Analysis:
  ├─ Development: Time-based (today)
  ├─ Cloudflare Pages: Free (500 builds/month)
  ├─ Cloudflare Workers: Free (100k requests/day, unused for MVP)
  ├─ Custom Domain: $10-15/year (optional)
  ├─ SSL Certificate: Free (Cloudflare managed)
  ├─ Web Analytics: Free (Cloudflare included)
  └─ Total Monthly Cost: $0 (free tier) or $1.25/month (domain amortized)
